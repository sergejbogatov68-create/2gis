# Контур — локальная студия агентов

Работающий локальный MVP для подготовки списка компаний и ручного запуска отдельных агентов. Интерфейс полностью на русском. Реальных или демонстрационных компаний в рабочей базе изначально нет.

## Быстрый запуск в Windows

1. Откройте папку `D:\D\CODEX\Site\agent-workspace`.
2. Дважды щёлкните **Start.cmd** или ярлык **Контур** на рабочем столе.
3. Браузер откроется автоматически по адресу **http://127.0.0.1:4317**. Сервер продолжит работать в фоне; повторный запуск использует тот же процесс.

Нужен **Node.js 24 или новее**. Запускатель также умеет использовать Node из установленной среды Codex на этом компьютере. Пакеты из npm устанавливать не нужно.

Через терминал:

```powershell
cd D:\D\CODEX\Site\agent-workspace
node server.mjs
```

При ручном запуске `node server.mjs` остановка — `Ctrl+C` в окне сервера. После запуска через ярлык используйте **Stop.cmd** в папке приложения. Текущие задания при остановке прервутся; после нового запуска они будут помечены как приостановленные. Закрытие вкладки браузера не останавливает сервер. Если порт занят другой программой или другой копией Контура, запускатель покажет ошибку и не затронет чужой процесс. Можно задать другой `PORT` в `.env`. Приложение слушает только `127.0.0.1`, не публикуется в интернете.

Ярлык уже создан на этом компьютере. На другом компьютере можно запустить `scripts/Install-DesktopShortcut.ps1` в PowerShell из папки проекта: скрипт создаёт значок и ярлык на рабочем столе текущего пользователя, сохраняя чужие ярлыки. Важное условие: не перемещайте папку приложения после создания ярлыка; если переместили — создайте ярлык заново. `.gitattributes` сохраняет переводы строк CMD-файлов в формате Windows.

## Что уже работает

- Поиск по городу, району, категориям, дополнительным запросам и лимиту 1–100.
- Ручной помощник без API-ключа: формирует ссылки на поисковые запросы в 2ГИС и сохраняет план запуска.
- Адаптер официального Places API: разрешённый поиск, ограничение частоты запросов, остановка при ограничениях источника, добавление результатов в базу, распознавание известных крупных сетей.
- Ручное добавление и редактирование карточек: название, категория, описание, город, район, адрес, рабочий телефон, карточка 2ГИС, сайт, источники, дата, статусы и заметки.
- Три результата проверки сайта, история изменений доказательств, отдельные отметки «Проверен» и «Неподходящий».
- Поиск по локальной базе, фильтры по сайту, статусу лида, проверенности, городу, категории, телефону и сети; сортировки по названию, дате и проверяемому приоритету.
- Импорт CSV/JSON, отчёт по ошибкам строк, пропуск дубликатов без замены ваших заметок.
- Экспорт текущего отфильтрованного списка в **CSV UTF-8 с BOM** и настоящий **XLSX**.
- Создание, редактирование, копирование, запуск, приостановка, возобновление и удаление агентов из списка.
- Создание агента из обычного описания задачи: описание переносится в редактируемую форму. Автоматического подбора полномочий нет.
- Четыре редактируемых шаблона: исследование, сравнение предложений, разбор файлов и подготовка отчёта. Можно создавать свои шаблоны.
- Отдельные настройки, выбранные файлы и собственная история каждого агента. Для запуска сохраняются настройки и материалы на тот момент.
- Загрузка текстовых TXT/MD/CSV/JSON в UTF-8 до 500 КБ; подключение конкретных файлов к конкретным агентам.
- Подключение локального Ollama или совместимого с Chat Completions сервера модели.

## Первый список компаний без ключа

1. На вкладке **Компании** укажите настоящий город и интересующие ниши. Нажмите **Подготовить поиск**.
2. Откройте нужный запрос из результата. Просматривайте сервис самостоятельно, соблюдая его условия. Приложение не читает страницы 2ГИС и не обходит защиту.
3. Нажмите **Добавить компанию**. Вносите только данные, которые вы вправе сохранять и использовать. Минимум — название и ссылка на источник; телефон должен быть публичным рабочим контактом компании.
4. Оставьте «Нужно проверить вручную», пока проверка не закончена. В карточке доступны ссылки на 2ГИС и поиск названия вместе с городом.
5. Зафиксируйте обоснование, источники и фактическую дату проверки. Для звонков выставьте «Готов к звонку»; для этого нужен телефон.
6. Отберите нужные записи и скачайте CSV или XLSX. Приложение само никому не звонит и ничего не отправляет.

Дата добавления записи/импорта **не** считается датой проверки. Если проверка не выполнялась, её дата остаётся пустой.

## Почему ключа 2ГИС недостаточно

В [оферте справочного WebAPI, пункт 3.1](https://law.2gis.ru/webapi-offer/) есть ограничение на извлечение, сохранение и дальнейшее использование данных вне предусмотренных договором способов; кэширование не предусмотрено. Поэтому обычный API-ключ, включая демонстрационный, сам по себе не подтверждает право создавать долговременную базу лидов и экспортировать её.

Для автоматического наполнения нужно согласовать с 2ГИС подходящее разрешение/договор на ваш сценарий — поиск клиентов, хранение, обработку и экспорт. [Официальные условия предоставления выборок](https://law.2gis.ru/sample-rules) — отдельный источник для обсуждения разрешённой выгрузки. Ручной режим не является разрешением копировать чужую базу: импортируйте и сохраняйте только данные, на использование которых у вас есть права.

После согласования:

1. Скопируйте `.env.example` в `.env` рядом с `server.mjs`.
2. Заполните:

```dotenv
DGIS_API_KEY=ваш_ключ
DGIS_STORAGE_LICENSE_CONFIRMED=true
DGIS_CONTACTS_ENABLED=false
```

3. Перезапустите приложение и выберите **Через API 2ГИС**.

`DGIS_STORAGE_LICENSE_CONFIRMED=true` — ваше явное подтверждение подходящего разрешения; приложение не проверяет договор и не приобретает лицензию. Без ключа и этой настройки сервер не выполняет автоматический поиск.

Контакты находятся в `items.contact_groups` и требуют [дополнительного разрешения ключа](https://docs.2gis.com/en/api/search/places/overview#additional-information-on-demand). Только после его получения поставьте `DGIS_CONTACTS_ENABLED=true`. Пропущенное поле контактов не является доказательством отсутствия телефона или сайта.

Запросы идут последовательно, с интервалом 1000–60000 мс (по умолчанию 1500), максимум 22 запроса за запуск и 5 страниц на запрос категории. Сверьте интервал с вашим тарифом. Ошибки 403/429 не обходятся и не перезапрашиваются автоматически. При достижении внутреннего предела приложение возвращает меньше компаний и объясняет причину. В этой версии география определяется по однозначному названию города и, при необходимости, района; при неоднозначности поиск останавливается. Для отдельных районов и населённых пунктов может потребоваться уточнение названия.

## Правила проверки сайта

| Статус | Какие сведения обязательны |
| --- | --- |
| Нужно проверить вручную | Источник записи. Используется по умолчанию, в том числе для кандидата на сайт или профиля соцсети. |
| Сайт найден | Полный URL, подтверждение принадлежности компании, обоснование, дата проверки. Известные соцсети и каталоги не принимаются за официальный сайт. |
| Сайт не найден при проверке | Город, ссылка на карточку 2ГИС, отметки проверки карточки и независимого поиска, отдельный источник поиска, дата и обоснование. Найденного адреса сайта в поле быть не должно. |

Это фиксация проверки пользователя, а не автоматическое подтверждение фактов в интернете. Отрицательный результат не означает, что сайта точно нет. У моделей нет браузера; они не меняют статусы компаний по своим предположениям.

Приоритет сортировки прозрачен: сначала подходящие компании с рабочим телефоном и отрицательным результатом проверки сайта; затем с телефоном и неопределённым сайтом; затем остальные. Неподходящие — в конце. Придуманных оценок потребности бизнеса нет.

Сети с **10 и более филиалами**, если это число вернул API, можно исключить. Если число филиалов или совпадение категории неясно, это отмечается для ручной проверки. Неполные данные не позволяют надёжно исключить все сети.

## Импорт и дубликаты

Пустой CSV-шаблон скачивается в окне импорта. Разделитель `;` или `,`, кодировка UTF-8. Основные колонки:

```text
name;category;city;district;address;phone;card_url;website;sources;notes
```

В `sources` разделяйте полные ссылки символом `|` или переводом строки внутри кавычек. Вместо `sources` достаточно заполнить `card_url`: он добавится к источникам. Основные русские заголовки также поддерживаются. JSON — массив объектов с теми же именами полей. До 1000 компаний и 1 МБ за импорт. Ошибочные строки показываются отдельно, корректные сохраняются.

Для переноса уже выполненной проверки в JSON предусмотрены `website_status` (`manual`, `found`, `not_found`), `checked_at` (ISO 8601), `reason`, `card_checked`, `web_checked`, `official_confirmed`. Проверки обязательности остаются теми же. Без этих сведений строка сохраняется как требующая ручной проверки. В CSV логические значения — `true`, `да` или `1`.

Дубликаты определяются по ID/ссылке карточки, нормализованным названию и адресу, либо названию и телефону при отсутствии адреса. Разные явно указанные ID карточек сохраняются отдельно, чтобы не объединять филиалы. Общий телефон без совпадения названия не объединяет разные компании. Неоднозначные случаи проверьте вручную.

Экспорт CSV защищает ячейки с признаками формул префиксом `'`; XLSX хранит текст как строки. Экспорт — список для работы, а не полная резервная копия. CSV с русскими заголовками можно импортировать обратно для основных сведений; для переноса истории и всех настроек копируйте базу.

## Агенты и модель

Во вкладке **Мои агенты** создайте агента или выберите шаблон. Разрешённые источники:

- Текст, введённый перед запуском.
- Только выбранные загруженные файлы.
- До трёх завершённых результатов **этого же** агента.
- До 100 сохранённых компаний, если вы явно подключили базу компаний.

Доступ к источнику одновременно разрешает соответствующее чтение. Отдельно задаётся право создавать результат и обращаться к модели. Копирование агента и создание шаблона не переносят доступ к его файлам и истории.

Встроенный агент 2ГИС выполняет фиксированный сценарий поиска без модели. Его текстовое описание служит описанием процесса; поведение задают параметры поиска и разрешённые источники. Универсальные агенты выполняют редактируемые инструкции через подключённую модель.

**Сбор материалов без ИИ** работает сразу: сохраняет исходные материалы с метками источников и явно сообщает, что анализ не выполнялся. Это не имитация ответа ИИ. Для анализа выберите режим с моделью.

### Локальная модель Ollama

Установите Ollama из официального источника, загрузите подходящую вашему компьютеру модель и запустите сервер. Укажите именно имя установленной модели:

```dotenv
AI_PROVIDER=ollama
AI_BASE_URL=http://127.0.0.1:11434
AI_MODEL=имя_установленной_модели
AI_ALLOW_REMOTE=false
```

Перезапустите Контур. В **Настройках** нажмите **Проверить подключение**, затем в агенте выберите **Анализ с ИИ-моделью**. Для локального Ollama ключ обычно не нужен. Протокол: [POST /api/chat](https://docs.ollama.com/api/chat), без потоковой передачи. Приложение не устанавливает Ollama и не скачивает модели самостоятельно.

### Совместимый сервер Chat Completions

```dotenv
AI_PROVIDER=compatible
AI_BASE_URL=https://ваш-сервер.example/v1
AI_MODEL=имя_модели
AI_API_KEY=ваш_ключ
AI_ALLOW_REMOTE=true
```

К базовому URL добавляется `/chat/completions`. Укажите API-ключ только в `.env`/переменной окружения. Для удалённого сервера обязательны HTTPS и явное `AI_ALLOW_REMOTE=true`. Разрешённые агенту материалы передаются выбранному серверу; интерфейс предупреждает об этом. Поддержка конкретной модели и доступность сервера зависят от провайдера. Для полностью локального сервера compatible используйте loopback URL, `AI_ALLOW_REMOTE` не требуется.

Модель не получает инструментов: нет командной строки, произвольного чтения диска, веб-обхода, звонков, рассылок, отправки сообщений или публикаций. Материалы считаются данными, а не командами. Лимит контекста — около 45 тысяч символов; сокращение сохраняется в истории. Ответ ИИ требует проверки человеком. JSON-ответ модели проверяется на корректность перед принятием.

Запуски выполняются в памяти работающего сервера; максимум три одновременно, один на агента. **Приостановка** отменяет активный запрос и запрещает новые запуски. Возобновление делает возможным новый ручной запуск, а не продолжает середину отменённого запроса. После перезапуска сервера прерванные запуски помечаются как приостановленные.

Удаление агента из списка архивирует его настройки. Результаты и история сохраняются, встроенный агент удалению не подлежит. Истории разных агентов не смешиваются.

## Данные и секреты

- SQLite: `data/kontur.sqlite`; загруженные текстовые файлы и история находятся в той же локальной базе.
- Для полной резервной копии **остановите сервер** и скопируйте папку `data` целиком. Не копируйте только основной файл SQLite во время работы: рядом могут находиться WAL-файлы.
- Ключи — только `.env` или окружение процесса. `.env` и `data/` исключены из Git.
- В браузер возвращается факт настройки ключа, а не его значение. Известные настроенные секреты и распространённые форматы токенов отсекаются при вводе/редактировании и маскируются в результатах.
- Не вставляйте произвольные секреты в материалы: детектор не может распознать все существующие форматы. База не шифруется и предназначена для личной работы на доверенном компьютере.
- Запись через HTTP требует токена локальной сессии; чужие Origin/Host блокируются. Приложение не рассчитано на публикацию сервера в сеть или совместную многопользовательскую работу.

## Проверки и ограничения MVP

```powershell
node --test tests/app.test.mjs tests/launcher.test.mjs
```

Проверки используют отдельные временные базы и тестовый сервер модели; рабочая база не меняется. Тестовые папки автоматически не удаляются. Результаты ручной проверки и снимки — в `validation/`.

Реальное наполнение через 2ГИС не проверено: в задаче не было рабочего ключа и разрешения на хранение. Реальный ответ ИИ не проверен без подключённой модели; протокол, изоляция материалов и отмена проверены локальным тестовым сервером. Приложение готово к подключению этих источников, но не сообщает, что они уже подключены. Запуск через настоящий ярлык проверен: приложение открывается, повторное открытие использует тот же процесс. Всего 19 автоматических тестов.

Оставшиеся границы: нет автоматического независимого веб-поиска сайтов, обхода страниц и CAPTCHA; разбор PDF/DOCX/XLSX нужно предварительно преобразовать в текст; нет планировщика и фонового исполнения при закрытом сервере, автоматических звонков или сообщений. Все решения о звонке и оценка корректности данных остаются за пользователем.

## Структура

```text
server.mjs             HTTP API, фоновые запуски и контроль доступа
src/domain.mjs         проверки карточек, дубликаты, фильтры, CSV-импорт
src/store.mjs          SQLite и стартовые шаблоны
src/integrations.mjs   официальный 2ГИС API и адаптеры моделей
src/launcher.mjs       безопасный запуск и остановка локального экземпляра
src/export.mjs         CSV и XLSX без внешних зависимостей
scripts/               запуск, остановка и установка ярлыка Windows
public/                интерфейс
tests/                 независимые проверки
docs/                  решения и проверенные источники
data/                  рабочие локальные данные (создаётся при запуске)
```
