# Копия проекта на GitHub и ярлык

Дата: 17 ноября 2026 года.

Пользователь попросил сохранить код на GitHub и открывать приложение ярлыком на рабочем столе. После входа он выбрал свой публичный репозиторий:

https://github.com/sergejbogatov68-create/2gis

В репозиторий включаются исходники, стартовые скрипты, шаблон окружения, тесты, документация и значок. Настоящий `.env`, SQLite-база, журналы, загруженные материалы, рабочая история, временные файлы и снимки из `validation/` исключаются. Публичная копия исходников не является резервной копией пользовательских данных.

Ярлык `Контур.lnk` на рабочем столе запускает `Start.cmd`. Запускатель находит Node.js, проверяет локальный экземпляр через `/api/health`, запускает сервер в фоне при необходимости и открывает браузер. Проверка использует идентификатор папки приложения; чужой процесс на том же порту не останавливается. Повторное открытие не создаёт второй сервер. Для остановки — `Stop.cmd`.

При проверке запуска выявлена особенность CMD с переводами строк LF. Файлы запуска приведены к CRLF; формат закреплён в `.gitattributes` для будущих копий из Git.

Полная резервная копия данных: остановить приложение и скопировать папку `data` целиком. Для восстановления исходников — скачать репозиторий и запустить `Start.cmd` на компьютере с Node.js 24+.
